## Method and limits

- Overview: all 35 seeds were entered in the keyword box as one list. Ahrefs truncates a comma list that is passed in the URL at about 200 characters, so the seeds were typed into the box.
- Ahrefs builds Matching terms, Related terms and Search suggestions from only **the 10 seeds in a list with the highest volume**. For the full seed list those were aviator, aviator predictor, aviator game, tower rush, chicken road, kasino tanzania, casino tanzania, live casino, roulette and online casino tanzania. To cover the other 25 seeds, Matching terms was also run on three more seed batches:
  - batch 2: jinsi ya kucheza aviator, blackjack, aviator tanzania, jetx, online slots, sloti, michezo ya kasino, crazy time, kasino mtandaoni, sweet bonanza (4,529 matching terms in total, SV 7.4K);
  - batch 3: aviator demo, aviator game tanzania, michezo ya sloti, crash games, aviatrix, mchezo wa aviator, big bass bonanza, gates of olympus, aviamasters, aviator strategy (442 matching terms in total);
  - batch 4: lightning roulette, space xy, mchezo wa ndege, crash royale, kasino mbashara (84 matching terms in total). Only "lightning roulette live" (10) was above 0-10; all the rest showed 0-10.
- Matching terms for the full seed list showed 15,533 keywords (SV 74K, GSV 12M). Pages 1-8 (400 rows) were read, sorted by volume. Rows still had volume 30 at row 400.
- Questions (Matching terms) showed 1,182 keywords (SV 2.0K). 100 rows were read; rows reach 0-10 on page 2.
- Related terms, "Also rank for" (top 100) showed 313 keywords; 150 rows were read. "Also talk about" (top 100) showed 97 keywords; all 97 were read.
- Search suggestions showed 4,722 keywords; 150 rows were read (row 150 = volume 10).
- Batch 2 and batch 3 rows at 0-10 were not kept (25 rows in batch 2, 10 rows in batch 3).
- The TSV keeps one row per keyword. `source_report` lists every report the keyword was seen in. Metrics come from the first report it was seen in; the same keyword showed the same metrics in every report checked.
- TP note: the multi-keyword list view showed "aviator" TP 1.2K. The single-keyword overview showed TP 1.7K (value $445). Both are as shown.
- `lang` is a rough automatic tag: sw = only Swahili words, mixed = Swahili plus English words, en = everything else (brand and game names count as neutral).
- Intent codes as Ahrefs shows them: I = informational, N = navigational, C = commercial, T = transactional; "branded" and "local" are Ahrefs' own flags.
- No keyword in any G3 report contains "dbbet".
