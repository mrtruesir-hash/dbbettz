## How to read the tables
- **Evidence** = numbers copied from the source files only, as clicks / impressions / position. "NA" = no number in any source. No volume is claimed here. Volumes come from the Ahrefs pull in the next step.
- **Section** = the new site section the seed would feed: How to start (APK, deposit, withdraw) · Betting (incl. esports) · Casino & Crash · Bonuses · Payment · Help. "Context" = not a target.
- **Flag** = an early call before Ahrefs data: TARGET, CHECK (measure first), CAUTION (likely avoid), CONTEXT (competitor, never a target).
- Lang: SW = Swahili, EN = English, MIX = brand or loanword plus either language.
